# fsp (RA2E1 demo copy)

A copy of selected files from [github.com/renesas/fsp](https://github.com/renesas/fsp)
at commit `6e2675336b37fbd805f0c01d5134adfdab4bf294`, kept in the same folder layout.

Contents: the ADC (r_adc), Low Power Modes (r_lpm), Flash (r_flash_lp) and Virtual EEPROM (rm_vee_flash) drivers with their API and instance headers, and the RA2E1 board-support (bsp/mcu/ra2e1) files.

Copied for a Trail demo of RA2E1 engineering-support research. All code is
Renesas Electronics' and stays under its original license (see LICENSE and the
SPDX header in each file). Nothing here has been modified.
